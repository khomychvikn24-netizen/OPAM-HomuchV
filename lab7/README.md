# Лабораторна робота №7. Узагальнені алгоритми, налаштовані делегатом

Виконала: Варвара, КН-3/1. Мета: відокремити незмінний алгоритм від критерію та дослідити захоплення змінних.

## Запуск і структура

.NET SDK 10: `dotnet run -c Release --project lab7/Lab07.csproj` із кореня репозиторію.
Algorithms.cs — Filter, Map, Aggregate, GroupBy. Data.cs — контейнер Student і дані з лабораторної 6. Program.cs — застосування, демонстрації й перевірки.

## Звіт

20 чисел [-3;3], Random(29); 12 слів із дефісами й без; 12 студентів із попередньої роботи.
Filter отримує критерії: числа <= 0, слова з дефісом, бали [60;89]. Розміри результатів — 12, 3 та 7. Тіло Filter між застосуваннями змінено **нуль разів**.
Map отримує перетворення: остача % (K % 7 + 2) = %5; верхній регістр; «Прізвище (бал)». У C# остача від'ємного числа може бути від'ємною.
GroupBy застосовано до студентів за групою, першою літерою та діапазоном балу; до слів — за довжиною. Є композиція Filter → Map. Конкретні типи, критерії та поля відсутні в тілах узагальнених алгоритмів, усі зміни поведінки надходять делегатами.

## Чотири агрегації: стан, старт, крок

**Сума**

Стан: long sum.

Старт: 0L.

Крок: sum + x.

**Добуток**

Стан: long product.

Старт: 1L.

Крок: product * x.

**Максимум**

Стан: int? best; null означає відсутність значення.

Старт: null.

Крок: якщо best відсутній або x > best, взяти x; інакше best.

**Середнє**

Стан: (long sum, int count).

Старт: (0L, 0).

Крок: (sum + x, count + 1).

Після одного проходу середнє = (double)sum / count; якщо count = 0, результат null. Власних циклів для цих чотирьох обчислень немає. Результати: сума 5, добуток 0, максимум 3, середнє 0,25.

## Захоплення змінних

```text
Поріг змінено: keep(4)=False
for: 3 3 3
foreach: 0 1 2
Виправлений for: 0 1 2
```

**Поріг.** Лямбда захоплює змінну threshold, а не знімок значення 3. Після присвоєння 1000 виклик порівнює 4 із 1000, тому повертає False; за початкового порога результат був би True.

**for.** Усі три лямбди посилаються на ту саму змінну i. Виклики відбуваються після завершення циклу, коли i = 3, тому кожен повертає 3.

**foreach.** У сучасному C# змінна ітерації окрема для кожної ітерації. Тому лямбди зберігають посилання на різні змінні зі значеннями 0, 1, 2.

Виправлення for: у тілі циклу створити `int copy = i` і захоплювати copy.

## Відповіді завдання 6

**Скільки функцій потрібно?** Без узагальнення та параметра-критерію для трьох типів і трьох критеріїв на кожен тип довелося б підтримувати до 9 окремих функцій відбору. Тут достатньо одного Filter<T> і дев'яти переданих критеріїв; у цій роботі фактично використано три критерії, по одному на тип, тому замінено три спеціалізовані функції однією. Сам алгоритм обходу не змінюється.

**Де узагальнення зайве?** IntStack із лаби 5 навмисно зберігає int і демонструє подвоєння масиву; для цієї навчальної мети достатньо одного типу. Створення додаткових абстракцій без потреби в інших типах ускладнило б пояснення приватного масиву й індексу вершини. Узагальнення доцільне, коли вже є кілька повторюваних застосувань.
