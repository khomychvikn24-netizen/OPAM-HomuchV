# Лабораторна робота №2. Алгоритми обробки масивів

Виконала: Варвара, КН-3/1. Мова: C#.

## Мета

Навчитися обчислювати характеристики масиву, відбирати елементи, знаходити серії, переставляти елементи на місці та обробляти рядки і стовпці матриці.

## Варіант і запуск

Перша літера імені В має номер 3 в українській абетці. Отже, 29 % 3 = 2, 29 % 4 = 1, 29 % 5 = 4.
Масив містить 16 чисел із [0; 5], критерій відбору — значення < 3, перестановка — обмін половин, матриця — 5 × 4.
Використано `new Random(29)` та `Next(0, 6)`, оскільки верхня межа Next не включається.
Матриця заповнюється тим самим генератором після масиву.

Потрібен .NET SDK 10. Із кореня репозиторію:

```console
dotnet run --project lab2/Lab02.csproj
```

Індекси масиву відраховуються від 0. Номер рядка матриці у виведенні — від 1.

## Хід роботи і методи

| Завдання | Метод | Реалізація |
|---|---|---|
| 1 | Analyze | За один прохід обчислює суму, дійсне середнє, мінімум і максимум з індексами, кількість нулів; повертає ознаку наявності результату |
| 2 | Filter | Двома проходами створює масив точного розміру зі значень < 3 |
| 3 | LongestSeries | Знаходить значення, довжину й початок першої найдовшої серії; повертає ознаку наявності результату |
| 4 | SwapHalves | Обмінює половини в тому самому масиві та повертає посилання на нього |
| 5 | AnalyzeMatrix | Повертає суми рядків, максимуми стовпців і індекс першого рядка з найбільшою сумою через out; bool позначає наявність результату |
| 6 | RunChecks | Автоматично перевіряє крайові й додаткові випадки; при помилці зупиняє програму |

Допоміжні методи PrintArray, PrintStatistics, PrintSeries та PrintMatrix відповідають за виведення. Main задає дані та викликає методи. LINQ і готові алгоритми обробки масивів не використовуються.
Для непарної довжини обмінюються дві рівні половини по обидва боки центрального елемента; центральний елемент не змінює позиції. Перестановка використовує O(1) додаткової пам'яті.

## Результати виконання

Початковий масив:

```text
[5, 1, 0, 4, 1, 5, 5, 5, 3, 5, 3, 0, 3, 3, 1, 0]
```

Сума — 44; середнє — 2,75; мінімум — 0, індекс 2; максимум — 5, індекс 0; кількість нулів — 3.
Результат фільтрації: `[1, 0, 1, 0, 1, 0]`.
Найдовша серія: значення 5, довжина 3, початковий індекс 5.

Після обміну половин:

```text
[3, 5, 3, 0, 3, 3, 1, 0, 5, 1, 0, 4, 1, 5, 5, 5]
```

Матриця:

```text
0  5  2  3
4  5  5  0
3  1  5  3
3  2  5  0
5  4  4  0
```

Суми рядків: `[10, 14, 12, 10, 13]`. Максимуми стовпців: `[5, 5, 5, 3]`.
Найбільша сума — 14 у рядку №2 (індекс 1).

## Перевірка крайових випадків

| Вхід | Завдання | Очікувано | Отримано |
|---|---|---|---|
| [] | 1 | Статистика не визначена | Повідомлення про невизначеність, OK |
| [] | 2 | [] | [], OK |
| [] | 3 | Серія не визначена | Повідомлення про невизначеність, OK |
| [] | 4 | [] без помилки | [], OK |
| [2] | 1 | Сума 2, середнє 2, min=max=2, індекси 0, нулів 0 | Усі значення збіглися, OK |
| [2] | 2 | [2] | [2], OK |
| [2] | 3 | Значення 2, довжина 1, початок 0 | (2, 1, 0), OK |
| [2] | 4 | [2] | [2], OK |
| [4,4,4,4] | 1 | Сума 16, середнє 4, min=max=4, перші індекси 0, нулів 0 | Усі значення збіглися, OK |
| [4,4,4,4] | 3 | Значення 4, довжина 4, початок 0 | (4, 4, 0), OK |

Додатково перевірено серію наприкінці `[1,2,2,2]`, рівні за довжиною серії `[1,1,2,2]`, перестановку парного та непарного масивів і матрицю з від'ємними значеннями та однаковими сумами рядків. Усі 15 автоматичних перевірок завершилися успішно на .NET SDK 10.0.401.

Помилок під час запуску не виявлено. Звернення до a[0] для порожнього масиву та ділення на нуль попереджено перевіркою довжини. Числові out-параметри при false не є результатом і не виводяться. Для порожнього масиву фільтрація та перестановка коректно повертають порожній масив; мінімум, максимум, середнє й серія не визначені.

## Пояснення для захисту

Окремих контрольних питань в умові немає. Нижче наведені відповіді про використані алгоритми.

1. **Чому середнє дійсне?** Перед діленням сума перетворюється на double, тому дробова частина зберігається.
2. **Як зберегти перший індекс максимуму?** Оновлювати його лише при строгому збільшенні значення, використовуючи >.
3. **Навіщо два проходи фільтрації?** Перший визначає точний розмір результату, другий заповнює його без зайвих елементів.
4. **Як врахувати серію в кінці?** Оновлювати найкращу серію відразу після обробки кожного елемента, включно з останнім.
5. **Чому перестановка не потребує іншого масиву?** Кожна пара елементів обмінюється через одну тимчасову змінну.
6. **Чому використовуються GetLength(0) і GetLength(1)?** Вони дають кількість рядків і стовпців; Length дає загальну кількість комірок.
7. **Яка складність?** Завдання 1–4 мають час O(n); фільтрація потребує O(m) пам'яті для m відібраних елементів. Матриця обробляється за O(r·c) часу та O(r+c) додаткової пам'яті для результатів.
8. **Чому максимум стовпця починається з першого рядка?** Так алгоритм правильно працює і тоді, коли всі значення від'ємні.

## Висновок

У роботі реалізовано алгоритми обробки масивів і матриць для варіанта 29. Характеристики масиву обчислено за один прохід, фільтрацію виконано в масив точного розміру, знайдено першу найдовшу серію та обміняно половини без другого масиву. Для матриці визначено суми рядків, максимуми стовпців і рядок із найбільшою сумою. Перевірки підтвердили правильну роботу на порожньому, одноелементному масивах, повторюваних значеннях і додаткових граничних випадках.
